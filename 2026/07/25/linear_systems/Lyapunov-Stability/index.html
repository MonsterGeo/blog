李雅普诺夫稳定性

这章节作为课题前置的基础知识学习笔记。

它包含以下内容： + 矩阵范数 + 李雅普诺夫稳定性 + 正定矩阵 + 离散时间 + 局部李雅普诺夫稳定性 + 使用MATLAB来实现测试

矩阵范数

矩阵范数有许多形式，对m × n矩阵A = [aij]来说，以下是常用的矩阵范数定义：

  • 1范数（绝对值距离）

$$ \Vert A\Vert_1 = \max_{i \leq j \leq n}\sum^m_{i= 1} \mid a_{ij}\mid $$

  • 无穷范数

$$ \Vert A\Vert_{\infty} = \max_{1 \leq i \leq m} \sum^{n}_{j=1}\mid a_{ij}\mid $$

对列向量v = [vi] ∈ Rℓ的特殊情况，我们这样定义无穷范数：‖v‖∞ = maxi ≤ i ≤ ℓ ∣ vi∣

  • 2范数

‖A‖2 = σmax[A]

其中δmax[A]表示矩阵A的最大奇异值1。对上述列向量v，它的2范数通常等于欧几里得范数$\sqrt{\sum^\ell_{i = 1}v^2_i}$2

  • Frobenius范数

$$ \Vert A\Vert_F = \sqrt{\sum^m_{i=1}\sum^n_{j=1}a^2_{ij}} = \sqrt{\sum^n_{i=1}\sigma_i[A]^2} $$

其中σi[A]是A的奇异值。同样的，若矩阵A替换为列向量，则自动变成2范数。

推导如下：

$$ tr(A^TA) = \sum^n_{j = 1}(A^TA)_{jj} = \sum^n_{j=1}\sum^m_{i=1}a^2_{ij} $$

就有‖A‖F2 = tr(ATA)

注意tr(A^TA) = $\sum^{r}_{i=1}\lambda_i(A^TA)$，其中λ是特征值。而$\sigma[A] = \sqrt{\lambda_i(A^TA)}$，根据奇异值的定义，那么矩阵A的奇异值就是A本身特征值算术平方根。

有

$$ tr(A^TA) = \sum^r_{i=1}\sigma_i[A]^2 \Rightarrow \Vert A\Vert_F = \sqrt{\sum^r_{i=1}\sigma_i[A]^2 } $$

范数在有限维空间下都是等价的，也就是说，无论我们选择什么样的范数，若矩阵A在一种范数下的值非常小，那么用另一种算出来也是很小的。某种定义下，他们可以是等价的。即存在一个常数c1, c2，使得c1‖A‖b ≤ ‖A‖a ≤ c2‖A‖b。我们有

$$ \begin{aligned} \frac{\Vert A\Vert_1}{\sqrt{n}}& \leq \vert A\Vert_2 \leq \sqrt{n}\Vert A\Vert_1\\ \frac{\Vert A\Vert_\infty}{\sqrt{n}} &\leq \vert A\Vert_2 \leq \sqrt{m}\Vert A\Vert_\infty\\ \frac{\Vert A\Vert_F}{\sqrt{n}} &\leq \vert A\Vert_2 \leq \Vert A\Vert_F\ \end{aligned} $$ 并且满足次乘的性质，对矩阵A, x我们有 ‖Ax‖p ≤ ‖A‖p‖x‖p, p ∈ {1, 2, ∞, F} 且 $$ \Vert A\Vert_p \geq \max_{x\neq 0}\frac{\Vert Ax\Vert_p}{\Vert x\Vert_p} $$

李雅普诺夫稳定性

你并不需要学习整本ode，这是工程问题，我们使用工程的方法来解决。本书是讲线性系统理论的。

李雅普诺夫的思路很简单，对于一般状态方程是一些常微分方程，我们并不能总找到有解的方法，实际上很多ode的解析解是不存在的或者数值解非常繁杂。那我们如何判断一个系统是稳定的呢，一个系统在某种情况下存在一个稳定点，也就是没有变化的地方ẋ = 0。那么我们要检查的就是这些方程的导数。在稳定点周围的能量是否是趋于稳定的（这一步依赖于我们构造能量函数），如果函数是负的，则说明能量逐渐减小，系统趋于稳定。那么我们就不需要去解ode也可以知道系统是什么样的

考虑一个连续的线性时变系统(CLTV)

ẋ = A(t)x + B(t)u, y = C(t)x + D(t)u, x ∈ Rn, u ∈ Rk, y ∈ Rm 其中ẋ是状态方程，A(t)是状态矩阵，B(t)是控制矩阵。y是输出方程。C是输出矩阵，D(t)是直接传输矩阵

我们可以实际考虑一维的方程，比如考虑一个方向的速度方程，他就是一个关于时间t的导数。

定义：李雅普诺夫稳定

一个系统（CLTV）我们说是稳定的，那么

  • [有界性] 在李雅普诺夫意义下，我们说他是内部稳定的，若对每个初始条件x(t0) = x0 ∈ Rn，其齐次状态3响应

x(t) = Φ(t, t0)x0, ∀t ≥ 0 都是一致有界。

  • [渐进稳定] 对每个初始条件x(t0) = x0 ∈ Rn，当t → ∞有x(t) → 0

  • [指数稳定] 若除此之外还存在常数c, λ > 0，使得对每个初始条件x(t0) = x0 ∈ Rn，都有

‖x(t)‖ ≤ ce−λ(t − t0)‖x(t0)‖, ∀t ≥ 0

原书印刷错误，应该是−λ

除此之外，我们则说他在李雅普诺夫意义下不是稳定的。

用线性衰减主要是因为对线性微分方程$\frac{dx}{dt} = -ax$的通解实际上带有一个e。

除了矩阵A之外的其他矩阵实际不太重要，该矩阵完全定义状态转移矩阵Φ。因此我们一般只讨论这个齐次系统

李雅普诺夫稳定性的特征值条件

定理：特征值条件

一个系统称为齐次连续时间线性时不变系统（H-CLTI），则

  • 临界稳定的，当且仅当A的特征值都具有小于或等于零的实部，并且所有对应实部为0的特征值的若尔当块尺寸为1 × 1
  • 渐进稳定的，当且仅当A的所有特征值实部都是负的。
  • 指数稳定，当且仅当A的所有特征值也是实部为负 除此之外我们说系统是不稳定的。当且仅当矩阵A的特征值至少有一个正实部或者存在实部为零的特征值对应的尺寸大于1 × 1的若尔当快

这里条件2和条件3是等价的。当若尔当块尺寸为1 × 1的时候，解带有sin , cos ，若大于1会存在指数项。

李雅普诺夫稳定性定理

李雅普诺夫稳定性定理提供了一种替代条件，用于检验连续时间下的齐次线性不变系统是否是稳定的。

ẋ = Ax           (H − CLTI)

定理：Lyapunov stability 下面五个条件是等价的

  1. H-CLTI系统是渐进稳定的
  2. H-CLTI系统是指数稳定的
  3. 矩阵A所有特征值均具有严格负实部
  4. 对每个对称的正定矩阵Q，存在唯一的矩阵P满足下述Lyapunov方程

A′P + PA = −Q

其中P是对称的正定矩阵

  1. 存在对称正定矩阵P使得

A′P + PA < 0

证明： 1，2，3已经证明完毕，我们通过证明下述方程是唯一解证明2能推导出4。

P = ∫0∞eA′tQeAtdt

我们通过4个步骤证明，首先P是收敛的，然后验证满足方程解。第三部证明矩阵正定，最后我们证明唯一

  • 步骤1，利用指数稳定，我们说当矩阵特征值都是实部严格负的情况下，eAt的元素会以指数级速度衰减到0。

我们证明该命题。

首先，若J是一个若尔当块，那么可以有如下分解：对每个i，Ji = λiI + Ni，其中Ji是第i个若尔当块，而Ni是幂零矩阵，对某个d ∈ ℤ， Nid = 0，而λi是第i个特征值。

那么，对矩阵A，它的一个分解为A = PJP−1，其中J是若尔当块。且J = diag(J1, ⋯, Jr)，因此eAt = PeJtP−1，我们研究其中的每一个若尔当块eJit。

由于Ji = λiI + Ni，因此eJit = eλit ⋅ IeNit。现在我们展开幂零矩阵。得到

$$ e^{N_it} = I+tN_i+\frac{t^2}{2!}N_i^2+\cdots + \frac{t^{m_i-1}}{(m_i-1)!}N_i^{m_i-1} $$

其中mi是第i个使得Ni为零的指数。所以上述式子是有限多项的。现在，由于这些项有限，那么对矩阵范数‖eNit‖，存在常数Ci，它是一个常数，可以由多项式展开Ni中的每个幂零矩阵和其他的数合并来，因此我们有‖eNit‖ ≤ Ci(1 + t + t2 + ⋯ + tmi − 1)。

现在，由于特征值实部为负，那么我们设α = −maxiRe(λi) > 0

那么所有特征值就满足Re(λi) ≤ −α。那么‖eλit‖ ≤ eRe(λi)t ≤ e−αt

整合不等式我们得到

‖eJit‖ ≤ Ci(1 + t + t2 + ⋯ + tmi − 1)e−αt ≤ Mie−αt

当趋于无穷的时候，这里的e−αt(t → ∞)快速的趋于0。利用矩阵范数，矩阵中的每个元素的绝对值都不可能超过矩阵范数。因此趋向无穷的时候矩阵的每个元素都快速趋于0、

回到证明上来，因此积分P的被积函数将会迅速的收敛到0.积分是绝对收敛的。

  • 步骤2 我们证明A′P + PA = −Q

首先

A′P + PA = ∫0∞A′eA′tQeAt + eA′tQeAtAdt

注意

$$ \frac{d}{dt} (e^{A't}Qe^{At}) = A'e^{A't}Qe^{At}+e^{A't}Qe^{At}A $$

因此

$$ A'P+PA = \left(\lim\limits_{t\to\infty}e^{A't}Qe^{At} - e^{A'0}Qe^{A0} \right) = -Q $$

其中因为是指数稳定的，极限那部分的指数t → ∞的时候eAt = 0，而eA0 = I。

  • 步骤3 我们证明P是对称和正定的。

P′ = ∫0∞(eA′tQeAt)′dt = ∫0∞(eAt)′Q′(eA′t)′dt = P

其中P′是P的转置

正定性则使用如下定义：

若Q是正定的，则对任意向量x ∈ Rn有xTQx > 0，其中Q ∈ Rn × n

由于Q正定，对任意t ≥ 0，xPx > 0。由于eAt非负，正定是很容易证明的。

  • 步骤四，唯一性

我们假定这样的P存在2个，分别是P和P̂。

那么

$$ \frac{d}{dt}(e^{A't}(P-\hat{P})e^{At}) = e^{A't}A'(P-\hat{P})e^{At}+e^{A't}(P-\hat{P})Ae^{At} = 0 $$

这是因为A′(P − P̂) − (P − P̂)A = 0

最后，由于A′P + PA = −Q，而Q正定，因此 A′P + PA ≤ 0

然后我们从5推导2.

我们需要构造李雅普诺夫函数，考虑标量信号4，V(x) = x′(t)Px(t)

取它的导数

v̇ = ẋ′Px + x′Pẋ = x′(A′P + PA)x = −x′Qx ≤ 0

由于Q ≥ 0正定，因此导数稳定下降。所以系统是不会发散的。

接着我们关注矩阵中的状态会是什么变化。使用瑞丽商定理（对正定矩阵），我们有如下不等式

λmin[P]‖x‖2 ≤ x′Px ≤ λmax[P]‖x‖2

现在我们证明是指数稳定的

由于v = x′Px ≥ λmin[P]‖x‖2，那么

$$ \Vert x(t)\Vert^2 \leq \frac{x'(t)Px(t)}{\lambda_{\min}[P]} $$

$$ \dot{x} = -x'Qx\leq -\lambda_{\min}[Q]\Vert x\Vert^2 \leq -\frac{\lambda_{\min}[Q]}{\lambda_{\max}[P]}v $$

引入比较原理5，$\dot{v(t)} \leq -c v(t)$，这个不等式的解不会超过微分方程的解，那么

v(t) ≤ v(0)e−ct

结合上面‖x(t)‖2的不等式，就有

‖x(t)‖ ≤ K‖x(0)‖e−ct

是指数稳定的

  1. 最大奇异值：矩阵对任意方向单位的最大放大值。↩︎

  2. $\sqrt{\sigma_{\max}(v^T v)} = \sqrt{(v_1,\cdots,v_n)\cdot \begin{bmatrix} v_1\\ \cdots\\ v_n \end{bmatrix}} = \sqrt{v_1^2+\cdots+v_n^2}=\sqrt{\sum^\ell_{i = 1}v^2_i}$↩︎

  3. 齐次系统就是状态方程，但去掉关于外部输入的那项，剩下的就是只依赖系统内部状态的方程A(t)x↩︎

  4. 就是系统中的每一个状态。↩︎

  5. 比较原理：令v(x)是如下可微的标量信号v(x)那么有：v̇(t) ≤ μv(t), μ ∈ ℝ↩︎
